# Preview provenance

The root [preview.png](../../preview.png) and `settings.png` capture the application's Qt Quick
presentation, rendered offscreen with `make previews`. The compact/expanded views
are arranged together for documentation; they are not two running desktop islands.

Lyrics and timing come from the original `fixtures/demo.json`; artwork comes from
`assets/demo-cover.svg`. No Spotify account, real listening history, upstream
screenshot, third-party lyrics or album cover was captured. Settings show demo mode.

Visual reference: **Lyricify / Dynamic Lyrics Island, WXRIW / XY Wang**,
https://github.com/WXRIW/Lyricify-App#lyricify-%E5%8E%9F%E5%88%9B .
Changes: Omarchy/Qt Quick implementation, bilingual rendering, Linux controls and
settings, and this documentation composition by omarchy-lyricify contributors.
